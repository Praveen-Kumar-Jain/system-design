# Study Map

Use this folder as the main index for your learning repository.

## Sections
- Frontend: user interfaces, client architecture, rendering, performance, and state management
- Backend: APIs, services, authentication, caching, queues, deployment, and reliability
- Database: schema design, SQL vs NoSQL, indexing, replication, consistency, and storage trade-offs
- Architecture: scalability, distributed systems, design patterns, and system trade-offs
- Research: articles, comparisons, references, and study notes

## Suggested workflow
1. Research a topic in the relevant section.
2. Write a short summary with key takeaways.
3. Add one architecture example or design note.
4. Compare alternatives and capture trade-offs.
